# RoleLogic v1.3.2

_Released December 29, 2025_

---

## Bug Fixes & Improvements

- Fixed cross-guild logging: when triggered from Guild B, logs are now correctly posted to Guild A where the rule is defined
- Added a UI to handle web render errors
- Web client now automatically reports render errors to the server
